# Security

Never commit credentials, tokens, certificates, private configuration or personal datasets. Ignore rules are not secret scanning: inspect staged content before every commit and push. Use synthetic inputs and isolated environments.

Networking and security experiments stay in authorized local laboratories; no third-party targeting. Offline financial simulations never handle real funds. Do not provision infrastructure, incur API charges or install system-wide dependencies without separate authorization. Assess file paths, permissions, untrusted input, unsafe deserialization and resource exhaustion as relevant to each implementation. Record limitations; do not advertise unverified production readiness.
