# Swiss Army Code Arsenal

A growing library of practical, reusable, documented and tested programming implementations across 25 technical domains. There is no fixed final application or completion date. Quality and usefulness take priority over file counts.

## Start here

- [Roadmap](ROADMAP.md): domain coverage and sequencing.

- [Contributing](CONTRIBUTING.md) and [operating rules](AGENTS.md).

This repository currently contains the project-management foundation only. Sprint 0001 is planned, not authorized or implemented. Domain directories describe future scope; they do not count as implemented coverage.

## Workflow

Request PLAN, STATUS, REVIEW, RETROSPECT or ROADMAP as needed. EXECUTE authorizes the current bounded sprint. Every future sprint needs fresh authorization. PAUSE stops initiation of new work.

No runtime dependencies are needed to read this foundation. Each future implementation will document its own setup and test commands. The repository is local-only by owner choice; licensing is pending; see [license status](LICENSE).
