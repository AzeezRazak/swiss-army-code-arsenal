# Multi-language projects

File: `projects/README.md`

Folder: `projects`

This folder holds complete multi-language projects requested by the owner. Create one named subfolder per project, such as `projects/local-dashboard/`, and keep all of that project's scripts, source, tests, examples and configuration together inside it. Organize by component or language where useful.

## Project requirements

Each project README must explain its purpose, folder layout, languages and their roles, runtime/dependency versions, setup, run and test commands, component interfaces, example inputs/outputs and known limitations. Follow the repository [coding standards](../DOCS/CODING-STANDARDS.md), including purpose comment blocks, explanatory comments and file/folder metadata in documents.

Use project-local dependency environments. Do not commit credentials, installed dependencies or generated build output. Add delivered projects and their scripts to the [catalog](../DOCS/CATALOG.md). Keep project-management records in [TODO](../TODO/CURRENT.md), linking to the project files.

No projects have been implemented yet. This folder is ready for future requests; creating it does not authorize a new project or sprint.
